# Interview Prep — База знаний для технических собеседований

Открытая база знаний для подготовки к техническим собеседованиям по Java и backend-разработке. Написана на русском языке.

Не определения ради галочки, а разбор **с кодом, ловушками с реальных собесов и объяснением почему это работает именно так**.

🔗 **Сайт:** https://bemyskyy.github.io/interview-prep/

---

## Что внутри

| Раздел | Темы |
|---|---|
| **Java** | JVM и память, основы языка, строки, современная Java, многопоточность, ООП, коллекции, исключения, дженерики, Stream API, IO/NIO, SOLID, паттерны |
| **Spring** | Core (IoC/DI/AOP), Spring Boot, MVC/REST, Data JPA и транзакции, Security, Spring Kafka, тестирование, кэширование, Actuator и Micrometer, WebFlux |
| **Данные** | SQL, ACID, MVCC, индексы, оконные функции, NoSQL, CAP-теорема, Redis, Cassandra |
| **Kafka** | Партиции, оффсеты, consumer groups, rebalancing, ISR, acks, семантики доставки, DLQ |
| **Computer Science** | Алгоритмы, Big O, структуры данных, сортировки, графы, паттерны LeetCode, сети (HTTP/TCP/TLS/gRPC) |
| **Проектирование** | Системный дизайн, масштабирование, кэширование, очереди, DDD, микросервисы, CQRS, Docker, CI/CD, K8s |

Каждая тема — **вопрос с собеса → ответ вслух → разбор с кодом → ловушки → проверь себя**, в конце страницы — шпаргалка.

Помимо тем на сайте есть:

- **Маршрут подготовки** на [главной](https://bemyskyy.github.io/interview-prep/#route) — что читать Junior, Middle и Senior и в каком порядке.
- **[За час до собеса](https://bemyskyy.github.io/interview-prep/prep/last-hour/)** — шпаргалки всех страниц на одной.
- **[Вопросы собеса](https://bemyskyy.github.io/interview-prep/prep/questions/)** — все вопросы базы со ссылками на ответы, для самопроверки.
- **[Теги](https://bemyskyy.github.io/interview-prep/prep/tags/)** — страницы по уровню и сквозным темам.
- **Глоссарий** — расшифровка сокращений (JMM, MVCC, ISR…) при наведении.

## Технологии

Сайт собран на [MkDocs](https://www.mkdocs.org/) с темой [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/). Контент — обычный Markdown, поэтому дополнять его может любой, кто умеет писать текст.

## Запуск локально

Нужен установленный Python 3.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/bemyskyy/interview-prep.git
cd interview-prep

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить локальный сервер с live-reload
mkdocs serve

# Открыть в браузере http://127.0.0.1:8000
```

Страницы обновляются автоматически при сохранении файлов.

Что подключено в `mkdocs.yml` и зачем:

| Расширение / плагин | Для чего |
|---|---|
| `pymdownx.snippets` | Шпаргалки страниц подключаются в «За час до собеса» по секции `cheatsheet`; глоссарий дописывается к каждой странице (`auto_append`) |
| `abbr` + `content.tooltips` | Подсказка с расшифровкой сокращения при наведении |
| `pymdownx.tabbed` + `content.tabs.link` | Вкладки «Коротко / Подробно» в длинных темах, выбор вкладки общий для всех страниц |
| `tags` | Теги уровня и темы, закрытый словарь `tags_allowed` |
| `attr_list` | Явные id заголовков: `### Вопрос? { #anchor }` |
| `md_in_html` | Вёрстка главной: первый экран и сетка разделов |
| `extra_css` + `theme.font: false` | Своё оформление из `docs/stylesheets/extra.css`, шрифты лежат локально, без Google Fonts |
| `theme.custom_dir: overrides` | Mermaid 11.17.2 из `docs/assets/vendor/mermaid/` вместо unpkg.com, только на страницах с диаграммами. Обновить версию — заменить `mermaid.min.js` файлом из npm-пакета `mermaid` |
| `hooks: scripts/prep_pages.py` | Сборка падает, если «Вопросы собеса», «За час до собеса» или числа страниц на главной устарели |
| `repo_url` + `content.action.edit` | Ссылка на репозиторий в шапке и кнопка «Редактировать» на страницах (у сгенерированных страниц её нет) |
| `site_url` + `navigation.footer` | Канонические ссылки и `sitemap.xml`; ссылки «Назад / Вперёд» внизу страницы |

## Стиль

Все страницы пишутся по [STYLE.md](STYLE.md). Коротко:

- Заголовок темы `###` — вопрос, как его задают на собесе, с явным id: `### Как HashMap находит бакет? { #bucket-index }`.
- Под ним `**Уровень:** Junior | Middle | Senior`, затем `!!! abstract "Ответ вслух"`, разбор с кодом, ловушки в `!!! warning`, `??? question "Проверь себя"`.
- Разбор длиннее 50 строк — во вкладках «Коротко / Подробно».
- В начале страницы — front matter с тегами уровня и темы, в конце — `## Шпаргалка { #cheatsheet }` в маркерах секции snippets.
- У каждой темы одна страница-«дом», остальные ссылаются на её якорь.

## Как добавить страницу

1. **Создай файл** в нужном разделе, например `docs/java/records.md`, по шаблону из [STYLE.md](STYLE.md):

    ````markdown
    ---
    tags:
      - Junior
      - Middle
      - Java
    ---

    # Records

    Вступление в 2–3 строки.

    ## Основы { #basics }

    ### Зачем нужны records? { #why-records }

    **Уровень:** Junior

    !!! abstract "Ответ вслух"
        2–3 предложения.

    Разбор с кодом.

    !!! warning "Ловушка"
        Текст.

    ??? question "Проверь себя"
        1. Вопрос?

    ## Шпаргалка { #cheatsheet }

    <!-- --8<-- [start:cheatsheet] -->
    | Тема | Запомнить |
    |---|---|
    | **Record** | Неизменяемый носитель данных |

    <!-- --8<-- [end:cheatsheet] -->
    ````

2. **Добавь страницу в `nav`** в `mkdocs.yml` — в нужный раздел и подраздел.
3. **Новый раздел верхнего уровня** — добавь ему id в `SECTION_IDS` в `scripts/prep_pages.py`.
4. **Новые сокращения** — в `includes/abbreviations.md`, новые теги — в `tags_allowed` в `mkdocs.yml` и в список тем в `docs/prep/tags.md`.
5. **Перегенерируй сводные страницы и проверь сборку:**

    ```bash
    python scripts/prep_pages.py
    mkdocs build --strict
    ```

    Новая страница сама появится в «Вопросах собеса» и «За час до собеса», а число страниц её раздела обновится на главной.

6. **Если тема подходит для маршрута** — добавь ссылку на неё в нужный уровень в разделе «Маршрут подготовки» в [docs/index.md](docs/index.md). Новый раздел верхнего уровня добавь и в блок «Разделы» на главной — без него сборка упадёт.

Новый вопрос на существующей странице добавляется так же: тема по шаблону, затем `python scripts/prep_pages.py`.

## Как внести вклад

Проект открытый и живёт за счёт сообщества. Помочь можно по-разному:

- **Нашёл ошибку или неточность** — открой [issue](https://github.com/bemyskyy/interview-prep/issues) или сразу присылай pull request: кнопка-карандаш «Редактировать» на странице сайта откроет её исходник на GitHub.
- **Знаешь тему глубже** — дополни существующую страницу.
- **Завалили вопросом, которого здесь нет** — добавь его разбор.
- **Хочешь новый раздел** — предложи в issue, обсудим.

### Как отправить pull request

Если раньше не работал с pull request — это проще, чем кажется:

```bash
# 1. Сделай форк репозитория (кнопка Fork вверху страницы на GitHub)

# 2. Клонируй свой форк
git clone https://github.com/ТВОЙ_ЛОГИН/interview-prep.git
cd interview-prep

# 3. Создай ветку для своих изменений
git checkout -b add-my-topic

# 4. Внеси правки в нужные .md файлы, проверь локально через mkdocs serve

# 5. Закоммить и запушь
git add .
git commit -m "Добавил разбор темы X"
git push origin add-my-topic

# 6. На GitHub нажми "Compare & pull request"
```

Не разобрался — напиши в комментариях под постом или в issue, помогу.

Перед PR проверь сборку: `python scripts/prep_pages.py && mkdocs build --strict`. Та же сборка запускается в каждом PR автоматически (проверка `check`), и PR с ошибкой сборки виден красным до мержа.
