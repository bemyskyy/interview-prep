# Подготовка к техническому собеседованию

Личная база знаний для backend-разработчика. Java, Spring, базы данных, алгоритмы, сети, системный дизайн и архитектура — всё, что реально спрашивают на собесах, с объяснением **почему** это работает именно так, а не просто определениями.

---

## С чего начать

Разделы вверху идут в логике изучения: от языка к фреймворку, от данных к проектированию систем. Внутри каждого — от базового к продвинутому.

**Готовишься к конкретному собесу?** Используй поиск (нажми ++s++ или ++/++) — он понимает русский и найдёт термин по всем страницам: `volatile`, `PECS`, `N+1`, `Circuit Breaker`, `MVCC`.

---

## Что внутри

### Язык Java
Платформа и память (JVM, GC, многопоточность), язык и API (ООП, коллекции, дженерики, Stream API), дизайн кода (SOLID, паттерны). Разбор до уровня байт-кода и Java Memory Model.

### Spring
Ядро (IoC, DI, AOP, жизненный цикл бина), веб и данные (MVC, REST, JPA, транзакции, N+1), экосистема (Security, Kafka, DDD, тестирование). От автоконфигурации до прокси под капотом.

### Данные
Реляционные (ACID, уровни изоляции, MVCC, индексы, оконные функции) и нереляционные (четыре семейства NoSQL, CAP-теорема, Redis, Cassandra, паттерны кэширования).

### Computer Science
Алгоритмы (Big O, структуры данных, сортировки, графы) с разбором паттернов LeetCode-задач. Сети (TCP/UDP, HTTP/1-3, TLS, REST vs gRPC, WebSocket, DNS).

### Проектирование
Системный дизайн (масштабирование, балансировка, кэширование, очереди, Saga), архитектура (DDD, микросервисы, CQRS, Event Sourcing, гексагональная архитектура), эксплуатация (Docker, CI/CD, Kubernetes, observability).

## Как устроены страницы

Каждая тема построена одинаково: **сначала суть и зачем нужно**, потом **код или схема**, потом **ловушки на собесах** в выделенных блоках, и **итоговая шпаргалка** в конце для быстрого повторения перед звонком.

!!! tip "Совет по подготовке"
    За день до собеса не пытайся прочитать всё. Открой шпаргалки в конце нужных страниц — они спроектированы как быстрое освежение уже изученного.
