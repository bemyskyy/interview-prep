    Подготовка к собеседованию на Java backend¶

    Язык, Spring, базы данных, Kafka, алгоритмы, сети и системный дизайн. Каждая тема — вопрос, как его задают на собесе, короткий ответ вслух и разбор с кодом: почему это работает именно так.

    Начать с основ Java Все разделы

    Вопрос с собеседования: что выведет код?

    Integer a = 127, b = 127;
Integer c = 128, d = 128;

System.out.println(a == b);
System.out.println(c == d);
    Ответ

    true, затем false. При автоупаковке компилятор вызывает Integer.valueOf(), а он отдаёт готовые объекты из кэша для значений от -128 до 127. a и b ссылаются на один объект из кэша, c и d — на два разных, а == сравнивает ссылки. Обёртки сравнивай через equals(). Подробнее — в ловушках автоупаковки.

    Маршрут подготовки¶

    Выбери свой уровень и иди по шагам сверху вниз. Каждый уровень включает предыдущий: Middle сначала проходит маршрут Junior, но может читать его быстрее — только «Ответ вслух» и ловушки.

    Цель — уверенно объяснить, что это, зачем и как этим пользоваться.

    1. Язык. Основы языка → Строки → ООП → Исключения.
    2. Коллекции и стримы. Коллекции → HashMap → Дженерики: основы → Stream API → Лямбды и Optional → Современная Java.
    3. Платформа. JVM: платформа → Сборка мусора → Stack и Heap → Потоки и synchronized.
    4. Базы данных. ACID → SQL-запросы → Индексы.
    5. Spring. Core: IoC и DI → Spring Boot → Spring MVC → Транзакции: @Transactional.
    6. Сети. TCP и UDP → HTTP → REST.
    7. Алгоритмы. Big O → Структуры данных → Подход к задаче → Two Pointers и HashMap в задачах.
    8. Окружение. Docker → Docker Compose.

    Для самопроверки ищи в Вопросах собеса пометку Junior.

    Цель — объяснить, как это устроено внутри, назвать сложность операций и типичные ошибки.

    1. Java целиком. Коллекции и потокобезопасные коллекции → Многопоточность: JMM и volatile → блокировки → пулы потоков и CompletableFuture → дедлоки → Память и сборка мусора → Дженерики: PECS и стирание типов → IO / NIO.
    2. Дизайн кода. Композиция и зацепление → SOLID → паттерны: порождающие, структурные и поведенческие.
    3. Spring изнутри. Жизненный цикл бина и AOP → Propagation → Блокировки → Hibernate и N+1 → Тестирование → Кэширование → Actuator и Micrometer → Spring Security → Kafka в Spring.
    4. Базы данных. Изоляция транзакций → MVCC → EXPLAIN ANALYZE → NoSQL.
    5. Kafka. Брокер: топики, партиции, хранение → Порядок, группы и ребаланс → Гарантии доставки.
    6. Сети. TLS → gRPC и выбор стиля API → WebSocket и SSE.
    7. Основы System Design. Строительные блоки → Надёжность микросервисов → Observability → CI/CD → Миграции БД.
    8. Алгоритмы. Все паттерны из задач на массивы и строки и на деревья, графы и ДП, включая динамическое программирование → Графы.

    Цель — граничные случаи, производительность, распределённые системы и обоснованный выбор архитектуры.

    1. JVM и конкурентность в глубину. Выбор сборщика мусора → Расследование OOM → Многопоточность под капотом: CAS, AQS, false sharing → Виртуальные потоки.
    2. Данные под нагрузкой. MVCC в PostgreSQL и MySQL → Почему не SERIALIZABLE везде → Lost update и write skew → Блокировки JPA.
    3. Kafka в проде. Ребаланс → Exactly-once → Log compaction.
    4. Распределённые системы. Распределённые данные: репликация, CAP, консенсус → Распределённые транзакции: Saga, Outbox → Микросервисы.
    5. Архитектура. DDD → Слоистая и гексагональная архитектура → CQRS и Event Sourcing → DDD в Spring-приложении.
    6. Интервью по System Design. Методология → Разбор кейсов.
    7. Эксплуатация. Миграции без простоя → Стратегии деплоя → Kubernetes.
