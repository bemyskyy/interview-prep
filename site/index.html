    Подготовка к техническому собеседованию¶

    Личная база знаний по Java и смежным технологиям. Здесь собрано всё, что реально спрашивают на собесах — с объяснением почему это работает именно так, а не просто определениями.

    Java¶

    Фундамент, без которого никуда. Разбираем не поверхностно, а до уровня байт-кода, JMM и архитектурных решений.

    Тема Что внутри
    Основы JVM JVM/JRE/JDK, Garbage Collector, Heap & Stack, Metaspace, OOM, примитивы, String Pool, autoboxing
    ООП Четыре кита, интерфейсы vs абстрактные классы, Override vs Overload, композиция vs наследование, Coupling & Cohesion
    Коллекции Иерархия, ArrayList vs LinkedList, HashMap под капотом (Java 8), TreeMap, HashSet, Comparable vs Comparator, PriorityQueue, ConcurrentHashMap
    Исключения Checked vs Unchecked, иерархия Throwable, try-with-resources, кастомные исключения, обработка в Spring
    Дженерики Type Erasure, Bridge Methods, Wildcards, PECS, запреты generics, Heap Pollution, @SafeVarargs
    Stream API Источники, промежуточные и терминальные операции, Collectors, groupingBy, Optional, функциональные интерфейсы, лямбды
    Многопоточность Thread vs Runnable, JMM, happens-before, volatile, synchronized, java.util.concurrent, CompletableFuture, Virtual Threads
    SOLID Все пять принципов с антипаттернами и реальными примерами на Java
    Паттерны проектирования Singleton, Builder, Factory, Decorator, Strategy, Observer — с кодом и объяснением когда применять
    IO / NIO java.io vs java.nio, Path & Files, потоковое чтение, BufferedReader/Writer, обход директорий

    Как пользоваться сайтом¶

    Поиск — самый быстрый способ найти нужный термин. Нажми ++s++ или ++/++ и начни вводить: HashMap, volatile, PECS, CompletableFuture — поиск подсветит все упоминания.

    Навигация — разделы в левом меню. Внутри каждой страницы — оглавление справа для быстрого перехода к нужному заголовку.

    Тёмная тема — переключается кнопкой в правом верхнем углу.
